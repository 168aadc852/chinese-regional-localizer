# Licence scope

The root `LICENSE` (Apache License 2.0) applies to project-authored software and project-authored documentation unless a file states otherwise.

It does **not** relicense third-party data, dictionaries, fixture rows derived from third-party open data, trademarks, or other external material. Those materials retain their own licences and conditions as recorded under `data-registry/`, file headers and `docs/LICENSE_PACKAGING.md`.

A generated SQLite data pack may therefore contain records with obligations different from the software licence. The build/import pipeline keeps core, attribution and share-alike packs separable and preserves source/version provenance.
