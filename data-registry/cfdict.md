# CFDICT

Status: **approved_with_conditions**

## Intended use
Traditional/Simplified lexical pairs, Pinyin, French lexical senses and cross-checking through a non-English bilingual source.

## Official source
Project page: https://chine.in/mandarin/dictionnaire/CFDICT/
Publisher: Chine Informations / CFDICT project

## Licence review
The official CFDICT page states that the project is distributed under **Creative Commons Attribution-ShareAlike 3.0 Unported (CC BY-SA 3.0)**.

The project page states that commercial and non-commercial use is allowed provided the source is credited, and that improvements/additions to the database are made available under the same licence.

- Commercial use: **Yes**
- Modification/adaptation: **Yes**
- Redistribution: **Yes**
- Attribution: **Required**
- ShareAlike: **Required** for adapted/improved database content

## Maintenance status
A September 2026 message from the project founder states that active development has been abandoned and the downloadable file remains available in its final/abandoned state.

This does not remove the existing open licence, but it means the dataset should be treated as **static/stale**, not as a source of current terminology.

## Packaging decision
Approved only in a separate ShareAlike-compatible lexical pack.

Use cases:
- additional Traditional/Simplified pair evidence;
- Pinyin cross-checking;
- historical/general lexical coverage;
- French sense cross-checks.

Do not treat CFDICT as a current regional naming authority.

## Update method
Pin and archive the last official downloadable XML/U8 snapshot used, with download date/hash where practical. Do not assume future upstream updates.
