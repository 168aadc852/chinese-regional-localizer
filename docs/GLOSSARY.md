# Project Glossary

- **Localization** — adapting language to a regional target, not just converting character forms.
- **Script conversion** — Simplified/Traditional or character-variant conversion.
- **Regional term** — terminology that differs across CN/HK/TW usage.
- **Entity** — a real-world or named concept such as a person, film, company, place or work.
- **Provenance** — information showing where a database claim originated.
- **Data pack** — a separable distributable dataset, potentially with its own licence obligations.
- **Protected term** — text that should not be automatically converted.
