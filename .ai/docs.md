# Documentation Tasks

Read only the document(s) being changed plus the implementation/source they describe.

Rules:
- keep current-state information in `PROJECT_STATE.md` concise;
- put historical detail in `docs/history/`;
- put durable architecture decisions in `docs/adr/`;
- do not duplicate the same rule across AGENTS/GEMINI/CLAUDE/Copilot files;
- prefer links to canonical details over copying long sections;
- update docs only when behavior, policy, architecture or user-facing workflow materially changes.

Do not preload the full documentation tree for a local documentation edit.
